# Full-Stack Habit Tracker

A beautiful, premium full-stack habit tracker app with a Node.js backend and pure HTML/CSS/JS frontend. 

## Structure
- `/backend` - Express API + SQLite database auto-creation 
- `/frontend` - Built with HTML, CSS (Variables, Flexbox, Animations), JS without reactive framework overhead.

## Quick Start
1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm run dev
   ```
4. Access the frontend app at `http://localhost:5000`
